# GenAI Tools

Sử dụng thành thạo các công cụ Generative AI (ChatGPT, Claude, Gemini) như một trợ lý đắc lực để tối ưu hóa quy trình làm việc (workflow), viết code nhanh hơn và khám phá ý tưởng phân tích.

### Các khái niệm cốt lõi

**1. Prompt Engineering (Kỹ nghệ câu lệnh)**
Kỹ năng viết câu lệnh rõ ràng, cung cấp đủ bối cảnh (context), role (vai trò), và định dạng (format) để AI trả về kết quả chính xác nhất.
*Ví dụ thao tác:* Cung cấp cấu trúc của bảng SQL và yêu cầu AI viết câu lệnh truy vấn Cohort Analysis thay vì phải tra cứu cú pháp từ đầu.

**2. Code Refactoring & Debugging**
Nhờ AI giải thích các đoạn code phức tạp, tối ưu hóa thuật toán hoặc tìm lỗi (bugs) trong các script Python/SQL.
*Ví dụ thao tác:* Paste một đoạn hàm Python xử lý dữ liệu chạy chậm và yêu cầu "Hãy tối ưu đoạn code này bằng phương pháp vectorization của NumPy".

**3. Data Interpretation (Hỗ trợ giải nghĩa dữ liệu)**
Đưa các kết quả phân tích thống kê (VD: các hệ số của mô hình hồi quy) để AI giúp diễn đạt lại thành ngôn ngữ kinh doanh dễ hiểu cho sếp hoặc khách hàng.
*Ví dụ thao tác:* "Dựa vào ma trận tương quan này, hãy viết 3 gạch đầu dòng báo cáo cho Giám đốc Marketing về mối quan hệ giữa chi phí Ads và doanh số."

**4. Workflow Automation Scripts**
Tạo nhanh các đoạn mã boilerplate (mã lặp lại) cho việc cào dữ liệu (web scraping), kết nối API, hay tự động hóa báo cáo Excel.
*Ví dụ thao tác:* "Viết một script Python sử dụng thư viện `openpyxl` để format tự động tất cả các file Excel trong thư mục `reports/`".

**5. Synthetic Data Generation (Tạo dữ liệu giả lập)**
Tạo các bộ dữ liệu giả ngẫu nhiên có quy luật để test các mô hình hoặc xây dựng biểu đồ mẫu trước khi có dữ liệu thật.
*Ví dụ thao tác:* Yêu cầu AI tạo một file CSV mẫu gồm 1000 dòng mô phỏng lịch sử mua hàng với các cột: ID, Ngày, Sản phẩm, Giá tiền.

### Ứng dụng thực tế
- Tăng tốc 50% thời gian viết các câu lệnh SQL phức tạp (nested subqueries, window functions) bằng cách dùng AI sinh mã nháp.
- Dùng AI để tóm tắt hàng ngàn dòng feedback phản hồi dạng text của người dùng thành 5 chủ đề (topics) chính.
- Nhanh chóng tìm ra nguyên nhân và cách sửa lỗi khi bảng dashboard kết nối database báo lỗi "Timeout" hoặc "Syntax Error".
