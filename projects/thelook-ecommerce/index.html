Xử Lý & Làm Sạch Dữ Liệu (Process)

Data Verification & Data Cleaning

🔍 Kiểm tra tính toàn vẹn

orders & order_items Rà soát cột status. Loại trừ Cancelled và Returned. Đảm bảo sale_price >= 0.
products Kiểm tra cột category không chứa NULL. Đảm bảo cost >= 0.
users Kiểm tra cột age để loại bỏ ngoại lai (tuổi âm hoặc > 120).

🧹 Làm sạch & Chuyển đổi

cleaning_orders.sql 
-- Làm sạch bảng orders: lọc trạng thái hợp lệ và chuyển đổi định dạng ngày
SELECT
  order_id,
  user_id,
  FORMAT_TIMESTAMP('%Y-%m', created_at) AS month_year,
  status
FROM `bigquery-public-data.thelook_ecommerce.orders`
WHERE status NOT IN ('Cancelled', 'Returned')
  AND created_at BETWEEN '2024-01-01' AND '2026-12-31';

Phân Tích & Trích Xuất Insight (Analyze)

Ad-hoc Analysis & Data Modeling

1. Tăng trưởng Đơn hàng & Khách hàng

Kết hợp COUNT(DISTINCT order_id) và COUNT(DISTINCT user_id). Dùng FORMAT_TIMESTAMP để gom nhóm theo tháng (2024-2026). Chỉ xét đơn hàng Complete / Shipped / Processing.

growth_metrics.sql 
SELECT
  FORMAT_TIMESTAMP('%Y-%m', created_at) AS month_year,
  COUNT(DISTINCT order_id) AS total_orders,
  COUNT(DISTINCT user_id) AS total_customers
FROM `bigquery-public-data.thelook_ecommerce.orders`
WHERE status IN ('Complete', 'Shipped', 'Processing')
  AND created_at BETWEEN '2024-01-01' AND '2026-12-31'
GROUP BY 1
ORDER BY 1;

2. Giá trị Đơn hàng Trung bình (AOV)

AOV = SUM(sale_price) / COUNT(DISTINCT order_id). Loại bỏ các mặt hàng bị trả lại để đảm bảo tính chuẩn xác cho bức tranh doanh thu.

calculate_aov.sql 
SELECT
  FORMAT_TIMESTAMP('%Y-%m', o.created_at) AS month_year,
  SUM(oi.sale_price) / COUNT(DISTINCT o.order_id) AS AOV
FROM `bigquery-public-data.thelook_ecommerce.orders` o
JOIN `bigquery-public-data.thelook_ecommerce.order_items` oi 
  ON o.order_id = oi.order_id
WHERE o.status NOT IN ('Cancelled', 'Returned')
  AND oi.status NOT IN ('Cancelled', 'Returned')
GROUP BY 1
ORDER BY 1;

3. Phân khúc Khách hàng theo Độ tuổi

Dùng CASE WHEN phân dải tuổi (<18, 18-24, 25-34, 35-44, >45). Nối bảng users và orders để đảm bảo chỉ phân nhóm những khách hàng thực sự phát sinh giao dịch.

customer_segments.sql 
SELECT
  CASE 
    WHEN u.age < 18 THEN '<18'
    WHEN u.age BETWEEN 18 AND 24 THEN '18-24'
    WHEN u.age BETWEEN 25 AND 34 THEN '25-34'
    WHEN u.age BETWEEN 35 AND 44 THEN '35-44'
    ELSE '>45'
  END AS age_group,
  COUNT(DISTINCT u.id) AS total_customers
FROM `bigquery-public-data.thelook_ecommerce.users` u
JOIN `bigquery-public-data.thelook_ecommerce.orders` o 
  ON u.id = o.user_id
WHERE o.status IN ('Complete', 'Shipped', 'Processing')
GROUP BY 1
ORDER BY age_group;

4. Xác định Top 5 Sản phẩm Bán chạy

Ứng dụng Window Function DENSE_RANK() OVER(PARTITION BY Month ORDER BY Revenue DESC) để phân bổ hạng và chọn lọc những sản phẩm xuất sắc nhất mỗi tháng.

top5_products.sql 
WITH product_sales AS (
  SELECT
    FORMAT_TIMESTAMP('%Y-%m', o.created_at) AS Month,
    p.name AS product_name,
    SUM(oi.sale_price) AS Revenue
  FROM orders o
  JOIN order_items oi ON o.order_id = oi.order_id
  JOIN products p ON oi.product_id = p.id
  WHERE o.status IN ('Complete', 'Shipped', 'Processing')
  GROUP BY 1, 2
),
ranked_products AS (
  SELECT
    *,
    DENSE_RANK() OVER(PARTITION BY Month ORDER BY Revenue DESC) AS rank_by_month
  FROM product_sales
)
SELECT * FROM ranked_products WHERE rank_by_month <= 5;

5. Thống kê Doanh thu theo Danh mục (Category)

Dùng GROUP BY category kết hợp ORDER BY total_revenue DESC để định vị "con gà đẻ trứng vàng" của hệ thống.

revenue_by_category.sql 
SELECT
  p.category,
  SUM(oi.sale_price) AS total_revenue
FROM orders o
JOIN order_items oi ON o.order_id = oi.order_id
JOIN products p ON oi.product_id = p.id
WHERE o.status IN ('Complete', 'Shipped', 'Processing')
GROUP BY 1
ORDER BY 2 DESC;

6. Khởi tạo Mô hình Dữ liệu (Data Modeling)

CTE + LAG()

Ứng dụng CTE để xây dựng Master Dataset. Tính toán MoM growth bằng Window Function LAG() OVER(...).

sales_growth_view.sql 
WITH base_data AS (
  SELECT
    FORMAT_TIMESTAMP('%Y-%m', o.created_at) AS month_year,
    p.category,
    SUM(oi.sale_price)           AS TPV,
    COUNT(DISTINCT o.order_id)  AS TPO,
    SUM(p.cost)                  AS total_cost
  FROM orders o
  JOIN order_items oi ON o.order_id = oi.order_id
  JOIN products p    ON oi.product_id = p.id
  WHERE o.status IN ('Complete', 'Shipped', 'Processing')
  GROUP BY 1, 2
)
SELECT
  *,
  TPV - LAG(TPV) OVER(PARTITION BY category ORDER BY month_year)
    AS revenue_growth
FROM base_data;
